# Клавиатура для Titan 2 / Elite / Pro

Клавиатура для **Titan 2, Titan 2 Elite и Titan 2 Elite Pro**.

Три раскладки: **английская**, **русский транслит**, **русский Ростест**.

## Установка

1. Откройте раздел **Releases** справа на странице проекта.
2. Скачайте файл **Titan2-Rostest.apk** напрямую (ZIP-архив не нужен).
3. Откройте APK на телефоне. При необходимости разрешите установку приложений из этого источника.
4. В настройках Android откройте раздел **Система → Языки и ввод → Экранная клавиатура / Управление клавиатурами**. Включите **«Клавиатура для Titan 2 / Elite / Pro»**.
5. Выберите эту клавиатуру в качестве используемого метода ввода.
6. Переключайте три раскладки сочетанием **Alt + Пробел**.

В раскладке Ростест **сначала вводится верхняя русская буква на клавише**, при следующем быстром нажатии — нижняя.

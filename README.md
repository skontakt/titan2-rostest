# Клавиатура для Titan 2 / Elite / Pro

Для **Titan 2**, **Titan 2 Elite** и **Titan 2 Elite Pro**.

Три раскладки: **английская**, **русский транслит** и **русский Ростест**. Переключение: **Alt + Пробел**.

## Установка

1. Откройте **Releases** и скачайте файл **Titan2-Rostest.apk** (не ZIP).
2. Удалите предыдущую версию перед установкой: ключ подписи новой версии отличается. При удалении сбрасываются настройки.
3. Откройте скачанный APK и установите приложение.
4. В настройках Android включите «Клавиатура для Titan 2 / Elite / Pro» и выберите её методом ввода.

## Безопасность

- **Полностью офлайн:** приложение не запрашивает разрешение INTERNET и не содержит функции проверки обновлений.
- **Нет истории ввода:** подсказки слов, предиктивный словарь и сохранение введённых слов удалены.
- **Нет буфера в клавиатуре:** история буфера, её мониторинг и кнопки копирования/вставки в панели удалены. Системное редактирование Android остаётся доступным.
- **Нет облачного копирования:** резервное копирование данных приложения отключено.
- **Нет службы специальных возможностей**, микрофона и голосового распознавания.
- **В релизной сборке отключено отладочное логирование.**
- Для работы клавиатура всё равно получает события вводимых клавиш; Android по этой причине показывает общее предупреждение о паролях и картах. Это не доказательство передачи данных.
- Ключ подписи этой сборки создаётся временно в CI, а не хранится в репозитории. Следующие обновления могут потребовать переустановки до настройки постоянного защищённого ключа.

Проверка исходников и разрешений в CI не заменяет инструментальную проверку поведения на физическом телефоне. Подробнее: [SECURITY.md](SECURITY.md).

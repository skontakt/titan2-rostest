# Проверка безопасности Titan2-Rostest Offline v2.0.0

## Назначение

Приложение работает как локальный Android Input Method Editor для физической клавиатуры Titan 2, Titan 2 Elite и Titan 2 Elite Pro. Поддерживает английскую раскладку, русский транслит и русский Ростест (Alt + Пробел).

## Отказ от доступа и сохранения данных

- Из AndroidManifest удалено разрешение `android.permission.INTERNET`. Приложение не имеет прямого доступа к сети.
- Удалены библиотека OkHttp и код проверки обновлений через GitHub API.
- Удалены предиктивные подсказки, пользовательский словарь частот слов и его сохранение.
- Удалены классы мониторинга и истории буфера обмена, клавиатурный вызов истории, кнопки клавиатуры для копирования, вставки и вырезания. Обычные функции других приложений и системы Android не изменены.
- Удалены голосовой ввод, вызовы внешнего распознавания речи и разрешение `RECORD_AUDIO`.
- Удалены служба специальных возможностей, её XML-манифест и код обхода окон других приложений.
- `android:allowBackup="false"`; удалены правила облачного копирования и переноса данных приложения.
- При запуске IME принудительно очищает имена старых локальных хранилищ `clipboard_history` и `user_word_history`, если они остались от прошлых версий.
- Настройки и локальные пользовательские раскладки остаются в хранилище приложения. Они не отправляются разработчику.
- В финальной сборке R8 удаляет обращения к диагностическому журналу `android.util.Log` для предотвращения записи вводимого текста.

## Дополнительные замечания

Метод ввода Android неизбежно обрабатывает нажатия и вводимые символы, включая пароли, когда он выбран в качестве активной клавиатуры. Стандартное предупреждение Android о паролях и картах нельзя и не нужно обходить.

Защита основана на исходном коде, разрешениях и проверке итоговой сборки CI. Она не доказывает абсолютную безопасность системного ПО, прошивки устройства, подключённых приложений и любых последующих изменённых APK. Для максимально высокой уверенности требуется независимый анализ APK и сетевых соединений на физическом устройстве.

Релизный APK подписан временным ключом, созданным на GitHub Actions, и не является отладочной сборкой. Этот ключ не хранится в репозитории и не обеспечивает обновление той же подписью в будущем. Перед установкой v2.0.0 понадобится удалить предыдущую версию; сохранённые настройки при этом теряются.

## Контроль в CI

Workflow собирает `assembleRelease`, проверяет APK через `apksigner verify` и перечень разрешений через `aapt dump permissions`. Наличие сетевых и чувствительных разрешений считается ошибкой сборки.
